# CustomerWeb source structure

- `assets/`: customer-facing images and static media.
- `components/`: reusable customer UI.
- `context/`: customer authentication and session state.
- `hooks/`: reusable React hooks for browser behavior.
- `pages/`: route-level customer screens.
- `services/`: API clients, DTOs, and external-service calls.
- `styles/`: ordered global, page, and component styles.
- `utils/`: navigation, cart storage, and pure helpers.
- `App.tsx`: application composition and page selection.
- `main.tsx`: DOM entry point.
