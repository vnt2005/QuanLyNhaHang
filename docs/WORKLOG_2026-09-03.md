## 1. Sửa phần tải báo cáo doanh thu xuống file Excel/CSV
- Kiểm tra lại luồng xuất báo cáo hiện tại từ màn `Chi tiết báo cáo doanh thu`.
- Giao diện file hiện tại khi mở bằng Excel/WPS còn thô, khó đọc và không có trình bày phù hợp.
- Phân biệt rõ hai mục đích:
  - CSV: giữ đúng bản chất file dữ liệu thuần, cấu trúc cột rõ ràng, encoding UTF-8/BOM phù hợp để Excel/WPS đọc tiếng Việt tốt.
  - XLSX/Excel: nếu cần giao diện đẹp thì tạo file workbook thực sự với tiêu đề, style, độ rộng cột, định dạng tiền/ngày, bảng món, căn lề và bố cục dễ đọc.
- Không giả lập style Excel bằng CSV vì CSV không hỗ trợ font, màu, merge cell hay định dạng bảng.
- Đảm bảo dữ liệu trong file tải xuống khớp chính xác số liệu đang hiển thị trên báo cáo: mã báo cáo, khoảng thời gian, số hóa đơn, số đơn, tổng tiền món, giảm giá, VAT, doanh thu và danh sách món.
