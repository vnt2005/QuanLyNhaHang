## 2. Chọn phương án miễn phí

- Thay vì mua domain riêng, dùng Cloudflare Worker public trên `workers.dev`.
- Kiến trúc mới:

~~~text
SePay
  ↓ HTTPS
https://sepay-webhook.quanlynhahang.workers.dev
  ↓
Cloudflare Worker
  ↓
https://<random>.trycloudflare.com
  ↓
http://localhost:8080
  ↓
QuanLyNhaHang API
~~~

- Worker chỉ proxy hai endpoint SePay cần thiết.
- Authorization header và request body được chuyển tiếp tới API local để backend tiếp tục tự xác thực và xử lý nghiệp vụ.

## 4. Tự động hóa Quick Tunnel + Worker deployment

Cập nhật:

~~~text
scripts/start-sepay-webhook-tunnel.ps1
~~~

Script hiện:

1. Kiểm tra API Gateway tại `http://localhost:8080/health/live`.
2. Tạo Cloudflare Quick Tunnel tới API local.
3. Lấy URL `trycloudflare.com` hiện tại.
4. Deploy Worker `sepay-webhook` bằng Wrangler.
5. Truyền Quick Tunnel hiện tại qua biến `UPSTREAM_ORIGIN`.
6. Sử dụng hostname ổn định `sepay-webhook.quanlynhahang.workers.dev`.
7. Gọi heartbeat qua Worker.
8. Chỉ mở readiness thanh toán QR khi heartbeat hợp lệ.
9. Duy trì heartbeat trong thời gian tunnel chạy.
10. Khi tunnel dừng, readiness hiện có của backend tiếp tục tự khóa QR sau thời gian timeout.

Quick Tunnel vẫn có thể đổi URL sau mỗi lần chạy, nhưng URL Webhook đưa vào SePay không còn phải đổi theo.
