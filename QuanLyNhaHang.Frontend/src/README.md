# WebApp source structure

- `assets/`: static images and media imported by the application.
- `components/`: reusable UI and feature components.
- `context/`: admin authentication and session state shared across the app.
- `hooks/`: reusable React hooks.
- `pages/`: route-level administration screens.
- `services/`: API clients, DTOs, and external-service calls.
- `styles/`: ordered global, page, component, and design-system styles.
- `utils/`: pure helpers and browser-storage utilities.
- `App.tsx`: application composition and page selection.
- `main.tsx`: DOM entry point.
